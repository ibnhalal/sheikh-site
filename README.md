# موقع الشيخ محمد زين بن آدم — نسخة Next.js / React

تحويل كامل للموقع الأصلي (HTML/CSS/JS ثابت) إلى تطبيق **Next.js 14 (App Router) + React 18 + Tailwind CSS** حديث وقابل للتشغيل والتطوير.

## المميزات المحفوظة من الموقع الأصلي
- تبديل اللغة (عربي / إنجليزي / أمهري) مع حفظ الاختيار في المتصفح
- الوضع الليلي/النهاري (Dark/Light Mode)
- شاشة ترحيب متحركة (Splash Screen) بشريط تحميل
- جميع الأقسام: التفسير، العقيدة، الفقه، الحديث، السيرة النبوية، اللغة العربية، آخر التحديثات، الأسئلة والاقتراحات
- كل الدروس الصوتية المرتبطة بأرشيف archive.org كما في الموقع الأصلي بالضبط
- أزرار تحميل PDF (الملفات المرفقة الأصلية تم تضمينها في `public/pdf`)
- تصميم متجاوب (Responsive) ودعم RTL/LTR تلقائي حسب اللغة

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح المتصفح على: **http://localhost:3000**

## البناء للإنتاج

```bash
npm run build
npm start
```

## كيف تربط الصوتيات الناقصة بأرشيف Archive.org

بعض الأقسام (الحديث، الفقه، اللغة العربية، آخر التحديثات) كانت في **موقعك الأصلي نفسه** تشير إلى مجلد أرشيف واحد مؤقت (`osoul-5`) لكل الكتب، وهو ما نقلته هذه النسخة بالضبط كما هو — أي أن هذه الروابط لم تكن مكتملة في الموقع الأصلي أصلاً، وليست خطأ حدث أثناء التحويل.

كل كتاب في المشروع معرّف بملف بيانات JS بسيط تحت `/data`، وفيه دالة `buildUrl(i)` هي المسؤولة عن توليد رابط كل درس. لتصحيح كتاب معيّن:

1. ارفع ملفات MP3 الخاصة بالكتاب على archive.org (أنشئ "Item" جديد لكل كتاب، بترقيم واضح للملفات مثل `bukhari (1).mp3`, `bukhari (2).mp3` ...).
2. افتح ملف البيانات المناسب:
   - `data/hadith.js` لقسم الحديث
   - `data/fiqh.js` لقسم الفقه
   - `data/language.js` لقسم اللغة العربية
   - `data/lastUpdate.js` لآخر التحديثات
   - `data/tafseer.js` و `data/aqeedah.js` للتفسير والعقيدة
3. غيّر اسم مجلد الأرشيف (`identifier`) داخل دالة `buildUrl` ليطابق الـ Item الذي أنشأته، مثال:

```js
// قبل
const buildUrl = (slug, i) => `https://archive.org/download/osoul-5/${slug}%20(${i}).mp3`;

// بعد (لو أنشأت Item منفصل لكل كتاب، مثلاً باسم الـ slug نفسه)
const buildUrl = (slug, i) => `https://archive.org/download/${slug}/${slug}%20(${i}).mp3`;
```

4. تأكد أن `total` (عدد الدروس) في نفس الملف يطابق العدد الحقيقي للملفات المرفوعة.
5. احفظ الملف وشغّل `npm run dev` — الرابط يتحدث تلقائياً لكل دروس الكتاب دفعة واحدة (لا حاجة لتعديل كل درس يدوياً).

> ملاحظة: لا يمكنني من مكان عملي الوصول إلى archive.org للتحقق من وجود الملفات فعلياً، لذا تأكد من رفعها بنفسك والتأكد من صحة الروابط عبر فتحها مباشرة في المتصفح قبل الاعتماد عليها.

## البحث الشامل

صندوق البحث في الصفحة الرئيسية يبحث الآن في **كل** محتوى الموقع (كل الأقسام وكل الكتب في كل قسم)، وليس فقط في بطاقات الصفحة الرئيسية كما في الموقع الأصلي. فهرس البحث موجود في `lib/searchIndex.js` ويُبنى تلقائياً من ملفات `/data` — أي كتاب جديد تضيفه لأي قسم يظهر في البحث تلقائياً دون أي تعديل إضافي.

## هيكل المشروع

```
app/                 صفحات المسارات (App Router)
  page.js            الصفحة الرئيسية
  tafseer/           قسم التفسير (صفحة القائمة + صفحة كل كتاب [slug])
  aqeedah/           قسم العقيدة (صفحة القائمة + صفحة كل كتاب [slug])
  hadith/            قسم الحديث (أكورديون كتب)
  fiqh/              قسم الفقه (أكورديون كتب)
  language/          قسم اللغة العربية (أكورديون كتب)
  last-update/       آخر التحديثات
  seerah/            قسم السيرة النبوية (تصميم ذهبي داكن خاص)
  help/              نموذج الأسئلة والاقتراحات
components/          مكونات React المشتركة (رأس الصفحة، مبدل اللغة، مشغل الصوت...)
context/             LanguageContext و ThemeContext (React Context)
data/                جميع بيانات الكتب والدروس والترجمات (يمكن تعديلها بسهولة)
public/pdf/          ملفات PDF المرفقة الأصلية
public/audio/seera/  مجلد فارغ لملفات صوتيات السيرة (انظر ملاحظة أدناه)
```

## ملاحظات مهمة

1. **صوتيات قسم السيرة النبوية**: في الموقع الأصلي كانت الروابط الصوتية والملفات PDF لقسم السيرة (`seerah.html`) تشير إلى مسارات محلية (`audio/seera/...`, `pdf/...`) لم تكن موجودة فعلياً داخل الملف المضغوط الذي أرسلته. تم الإبقاء على نفس بنية الروابط (`/audio/seera/<prefix>_<رقم>.mp3` و `/pdf/seerah-*.pdf`) بحيث يكفي وضع الملفات الفعلية في `public/audio/seera/` و `public/pdf/` بنفس التسمية ليعمل القسم بشكل كامل.

2. **إضافة/تعديل دروس أو كتب جديدة**: كل بيانات الأقسام موجودة في ملفات JS بسيطة داخل مجلد `data/` (مثل `data/tafseer.js`, `data/hadith.js`...). يمكنك إضافة كتاب جديد أو تعديل عدد الدروس أو رابط الأرشيف بتعديل هذه الملفات مباشرة دون الحاجة لمعرفة برمجية متقدمة.

3. **الألوان**: كل قسم له لون مميز (تركواز للتفسير، بنفسجي للعقيدة، أحمر للحديث، أخضر للفقه، أزرق للغة، ذهبي للسيرة) يمكن تغييره من نفس ملفات `data/`.

4. تم استخدام Google Fonts (Amiri, Noto Kufi Arabic, Tajawal) و Font Awesome عبر CDN كما في الموقع الأصلي — يتطلب اتصال إنترنت عند فتح الموقع لتحميل الخطوط والأيقونات.
